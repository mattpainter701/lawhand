# Add-on module management

[Add-on Modules](/plugins) is the catalog of specialized practice workflows, such as estate administration, domestic relations, mediation, and renewal tracking. What you can see and open depends on your firm's plan, what it has purchased or is trialing, each module's setup, and your role.

A visible card is not permission to use a module for client work. Confirm the module is active, set up, and approved for the work under your firm's procedure.

## Find an add-on

Open [Add-on Modules](/plugins). The tabs sort every module by state:

| Tab | What it means |
| --- | --- |
| **Purchased** | Your firm owns the module and it is set up. **Open Workspace** opens it. |
| **Trials** | Your firm is evaluating the module for a limited time. **Open Workspace** opens it. |
| **Setup Required** | Purchased, but the module needs configuration or a practice profile first. **Complete Setup** opens its setup. |
| **Available** | Not yet active for your firm. **View Add-on** describes it. |
| **Locked** | Disabled, or not included in your firm's plan. |

A card can also say **Expired** or **Scheduled** instead of its tab name. An expired trial stays expired even if its practice profile is complete, and a scheduled one is not active yet. Each card lists the module's category and the integrations it uses.

### Start, buy, or stop a module (administrators)

Administrators see extra buttons on each card:

- **Trial** starts an evaluation, and **Purchase** records that your firm bought the module. LawHand confirms with "Trial started for …" or "Purchased …".
- **Configure** opens the module's setup, and **Disable** takes it out of use.

## Complete a module's setup

A module usually needs a firm or practice profile before its results can be relied on. The module page shows **Profile Active** when setup is done, or **Setup Required** when it is not.

1. Open the module from its card (**Complete Setup** or **Configure**).
2. Select **Setup Workflow** (or **Edit Setup** to change an existing setup).
3. Answer with approved, firm-wide information: the jurisdictions you practice in, escalation rules, approval thresholds, house style, template preferences, and any cloud or calendar connections the module should use.
4. Review the generated profile and correct anything it assumed without support.
5. Tick **Mark setup complete and activate generated profile**, then select **Save Setup**.

Some modules still offer a **Legacy Interview**, a guided question-and-answer version of the same setup.

> [!IMPORTANT]
> A practice profile shapes later results for everyone at your firm. Do not put matter-specific facts, client secrets, or one lawyer's personal preferences into a shared profile unless that is the approved scope. Do not invent firm information just to finish setup; ask an administrator.

## Run a module's analysis

Each module lists its workflows on the left of its page. To run one:

1. Choose the workflow.
2. Choose the matter it concerns, or leave it with no matter context.
3. Paste the text to analyze, or select **Upload File** to read it from a document.
4. Turn on **Premium Model** for harder questions; it is slower but higher quality.
5. Select **Run** followed by the workflow's name.

The result appears under **Analysis Results**. Inspect every warning and validate each conclusion against the governing law and the record.

If LawHand says "The document was long and has been truncated", the analysis saw only part of the document. Split the document or paste the section you need, because anything outside the supplied part was not considered.

A result shown on screen is not automatically part of the client file. Save material sources and final work product to the matter.

## When setup or analysis fails

Read the message first. Common causes are an incomplete practice profile, a missing or unreadable document ("That file could not be read. Paste the text directly instead."), an expired or disabled module, or a disconnected integration. Avoid resubmitting repeatedly when a retry could duplicate work or use up your firm's allowance.

Contact an administrator about access, entitlement, the firm profile, integrations, or configuration. Include the module, the step, the time, the matter, and any request ID, but no unnecessary client content.

## Troubleshooting

| What you notice | Likely cause | What to do |
| --- | --- | --- |
| A module you expect is missing or **Locked** | It is not in your firm's plan, or it was disabled | Ask your administrator. |
| **Open Workspace** is not offered | The module needs setup, or it is not active | Select **Complete Setup**, or ask an administrator to activate it. |
| A card says **Expired** | The trial or subscription ended | Ask an administrator to renew or purchase it. |
| Results ignore part of your document | The document was truncated | Analyze it in sections. |
| "Failed to save setup." | A setup field is invalid, or the connection dropped | Check the highlighted fields and save again. |
